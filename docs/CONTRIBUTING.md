# Contributing to AI Frontiers Architecture Lab

Daily editions extend the growing monorepo. Prefer focused, tested additions over padding line counts.

## Layout

| Area | Purpose |
|---|---|
| `platform/` | Provider adapters, gateway, orchestration, cost |
| `projects/` | Runnable implementations by series/topic |
| `research/` | Evidence packets (mirrored from runs) |
| `evaluations/` | Datasets and reports |
| `diagrams/` | Architecture specs, Mermaid, SVG, PNG |
| `content/` | LinkedIn, X, WhatsApp copy |
| `reviews/` | Scores and selection records |
| `docs/` | Tutorials and design notes |

## Cadence

- **Daily:** one focused lesson, poster, tested example
- **Weekly:** deepen a related cluster into a stronger reference
- **Monthly:** flagship architecture with benchmarks and walkthrough

## Rules

- Authors never score their own candidates
- Publishing is an explicit stage (`send` / share)
- `publication_ready` stays false until human review
